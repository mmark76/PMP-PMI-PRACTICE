EVM

EVM — Βασικοί Τύποι

  • EV = % Complete × BAC
  • PV = Planned Value
  • AC = Actual Cost
  • CPI = EV / AC
  • SPI = EV / PV
  • ETC = EAC − AC
  • EAC = AC + (BAC − EV) / CPI
  • VAC = BAC − EAC

PROCESS vs PROCEDURE

Process vs Procedure

Process

Σύνολο ενεργειών ή βημάτων για συγκεκριμένο output. Περιγράφει τι πρέπει να γίνει, πότε και από ποιον. Συνήθως καθορίζεται από PMBOK ή methodology.

Procedure

Λεπτομερής οδηγός βήμα-βήμα για το πώς εκτελείται μια δραστηριότητα. Συνήθως καθορίζεται εσωτερικά ως OPA.
